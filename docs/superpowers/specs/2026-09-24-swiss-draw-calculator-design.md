# スイスドロー決勝進出人数計算サイト 設計書

- 作成日: 2026-09-24
- 状態: 承認済み（実装計画待ち）

## 1. 目的

参加人数を入力すると、スイスドロー予選の結果（成績ごとの人数とその確率）と、決勝トーナメント進出人数の確率を表示する Web サイト。GitHub Pages で一般公開する。

## 2. 用語

- **U**: 予選の全勝者数（5回戦終了なら 5-0、6回戦終了なら 6-0）
- **O**: 予選の1敗者数（5回戦終了なら 4-1、6回戦終了なら 5-1）
- **A** = U + O
- **枠**: 決勝トーナメントの規模（8 または 16）

## 3. 大会ルール（確定版）

### 3.1 予選回数

5回戦終了時の (4-1 の人数 + 5-0 の人数) を数える。

- 16 以下 → 予選は5回戦で終了
- 17 以上 → 予選は6回戦で終了

### 3.2 決勝トーナメント

予選終了時の U, O から以下で判定する。

1. 枠 = A ≤ 8 なら 8（決勝3回戦）、A ≥ 9 なら 16（決勝4回戦）
2. O + 2U > 枠 の場合（全勝者の Bye を入れると枠に収まらない）
   - 進出人数 = 枠、Bye = 0
   - 決勝全試合で予選勝利数の多いプレイヤーが先攻（先攻ルール適用）
3. それ以外
   - 全勝者 U 人が決勝1回戦 Bye
   - 進出人数 = 枠 − U、先攻ルール非適用

全勝者は「自分の枠」と「空いた対戦相手の枠」の2枠を使うため 2U と数える。

検証済みの例:

| 全勝 | 1敗 | 進出人数 | Bye | 先攻ルール |
|---|---|---|---|---|
| 3 | 12 | 16 | 0 | あり |
| 2 | 10 | 14 | 2 | なし |
| 1 | 15 | 16 | 0 | あり |
| 1 | 7 | 8 | 0 | あり |

### 3.3 対象外ケース

A > 16 となる状態はルール未定義。参加人数を 25〜128 人に制限することで実質発生しない見込みだが、発生した場合は「ルール対象外」として別集計し警告表示する。

## 4. 確率モデルの前提

- 参加人数: 25〜128 の整数
- 全試合で勝敗がつく（引き分け・ID・両者敗北なし）、ドロップなし
- 各試合の勝率は 50%
- ペアリング: 勝数の高いグループから順に同勝数同士で組む。グループが奇数人なら1人がすぐ下のグループと対戦（ペアダウン）。最下位で1人余ればその人が予選 Bye（1勝扱い）
- 同じ勝数のプレイヤーは区別しないため、状態は「勝数ごとの人数」のみで十分

## 5. 計算方式

厳密計算（動的計画法）。状態 = 勝数ごとの人数の配列。1回戦ごとに「状態 → (次状態, 確率)」の分布を展開し、同一状態はマージする。分岐はペアダウン戦（50/50）でのみ発生する。

処理の流れ:

1. 初期状態（全員0勝）から5回戦分を展開
2. 各状態で (4-1 + 5-0) を判定。17 以上なら6回戦目を展開
3. 各終了状態で決勝判定（3.2）
4. 確率を合算して表示用データを生成

## 6. 構成

技術: Vite + TypeScript、テストは Vitest、UI フレームワークなし。

```
src/
  swiss.ts       1回戦分の遷移: 状態 → 次状態の確率分布
  finals.ts      (U, O) → { 進出人数, Bye 数, 先攻ルール適用 }
  tournament.ts  全体統合: 5回戦 → 6回戦判定 → 集計
  main.ts        入力・結果描画
tests/
```

各モジュールは単一の責務を持ち、finals.ts は決勝ルールのみ、swiss.ts はペアリングと勝敗のみを扱う。

## 7. 画面

- **入力**: 参加人数と計算ボタン。範囲外・非整数はエラー表示し計算しない
- **結果1 予選回数**: 5回戦終了の確率 / 6回戦になる確率
- **ルール説明**: サイト名の直下に、予選回数と決勝進出（①〜④）のルールを簡潔に記載
- （最終成績の分布表は 2026-09-24 のユーザー要望により削除）
- **2敗からの進出人数** = 進出人数 − 全勝 − 1敗（全勝・1敗で埋まらない枠）。決勝は (進出人数, Bye, 先攻ルール) ごとにまとめ、2敗からの進出人数は最小〜最大の幅で表示する
- **前提条件の表示**: 勝率50%・引き分けなし・両者敗北なし
- **結果2 決勝トーナメント**: (進出人数, Bye 数, 先攻ルール) の組み合わせごとの確率（5回戦・6回戦を合算した全体確率）。枠は表示しない
- 対象外ケースが発生した場合は警告を表示
- 1カラムでスマホ対応

## 8. エラー処理

- 入力検証は main.ts で行い、計算関数も範囲外の入力には例外を投げる
- A > 16 の状態は対象外として別集計

## 9. テスト

- **swiss.ts**: 64人で決定的な結果になる / 奇数グループで 50/50 に分岐する / 人数保存 / 確率の合計 = 1
- **finals.ts**: 3.2 の検証済みの例をすべてテストする
- **tournament.ts**: 25人・128人で確率の合計 = 1 かつ高速に終わる / 小人数で総当たり列挙による素朴な実装と一致する

## 10. 公開

GitHub Actions で `npm run build` を実行し、GitHub Pages へデプロイする。リポジトリ作成・push は実施時にユーザーへ確認する。

## 11. 対象外

- 引き分け・ID・ドロップのモデル化
- 勝率の偏り（プレイヤーごとの強さ）
- 2敗以下の進出者の選出（タイブレーク）
