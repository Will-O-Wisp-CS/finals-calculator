# DMPランキングポイント計算ページ 設計書

- 作成日: 2026-09-27
- 状態: 承認済み（実装計画待ち）


## Context
既存の「鬼火CS 決勝トーナメント進出人数計算ツール」（Vite + TypeScript、GitHub Pages）と同じサイトに、
**自分の順位・参加人数・ジャッジ有無からDMPランキングポイントを計算するページ**を追加する。
ルールはユーザー提供の画像2枚（基礎ポイント表・下期倍率表）に基づく。

## ルール（計算仕様）

獲得pt = floor(基礎pt × 人数倍率 × ジャッジ倍率)　※対象外なら0

**基礎ポイント（順位）**: 1位1000 / 2位500 / 3-4位250 / 5-8位150 / 9-16位100 / 17-32位50 / 33-64位30 / 65-128位20 / 129-256位10

**人数倍率・ポイント対象者（参加人数）**
- 0-24: 0（対象0名）
- 25-29: 0.4 / 30-39: 0.6 / 40-49: 0.8（上位16名）
- 50-59: 1.0 〜 90-99: 1.8（10人ごと+0.2、上位32名）
- 100-199: 2.0 〜 3.8（10人ごと+0.2、上位64名）
- 200-449: 4.0 〜 6.4（10人ごと+0.1、上位128名）
- 450-499: 6.5 〜 6.9（10人ごと+0.1、上位256名）
- 500以上: 7.0（上位256名）

倍率は画像どおりの**明示テーブル**（下限人数・倍率・対象人数の配列）で持つ。式で生成しない（公式表との突き合わせを容易にするため）。

**ジャッジ倍率**: あり1.2 / なし1.0

**端数**: 切り捨て。浮動小数誤差対策として整数演算（倍率を×10、ジャッジを×10で整数化し、最後に÷100して floor）で計算する。
→ 未確定情報のため、ページの「前提条件」に「小数点以下は切り捨てとして計算（公式の端数処理は未確定）」と明記する。

## UI
入力カード（「計算する」）:
- 順位（テキスト, inputmode=numeric）
- 参加人数（テキスト, inputmode=numeric）
- ジャッジ（あり/なし のラジオ、デフォルト「なし」）
- 計算ボタン（既存と同じ submit 方式）
- 前提条件リスト: 小数点以下切り捨て（未確定）
- （129〜256位の基礎ポイント10ptは 2026-10-01 に公式確定したため前提条件から削除）

結果カード:
- 大きく「◯◯pt」
- 内訳: `基礎 30pt × 人数倍率 0.4 × ジャッジ 1.2 = 14.4 → 14pt`
- タグ: 「ポイント対象: 上位16名」
- 対象外の場合: 「0pt」＋理由（「参加25人未満のためポイント対象外」/「上位16名までが対象のため対象外」）

## エラー処理
- 空欄 / 非整数 / 1未満 → フィールドごとのメッセージ（`role="alert"`）
- 順位 > 参加人数 → 「順位は参加人数以下で入力してください」
- 参加人数の上限は設けない（500以上は倍率7）

## テスト（TDD）
- `basePoints`: 各順位帯の境界（1,2,3,4,5,8,9,16,17,32,33,64,65,128,129,256,257）
- `participantTier`: 各帯の境界（24/25, 29/30, 49/50, 99/100, 199/200, 449/450, 499/500, 1000）
- `calculatePoints`:
  - 10位/25人/あり → 100×0.4×1.2 = 48
  - 17位/25人/あり → 上位16名対象のため 0pt（対象外）
  - 1位/24人/なし → 参加25人未満のため 0pt
  - 40位/100人/あり → 30×2.0×1.2 = 72
  - 65位/210人/あり → 20×4.1×1.2 = 98.4 → 98（切り捨て）
  - 33位/60人/なし → 上位32名対象のため 0pt
  - 200位/450人/なし → 10×6.5 = 65
- 入力パース: 全角数字、空欄、小数、0、順位>人数
