# 鬼火CS 月別大会一覧 CSV

指定された月の鬼火CSを dmp-ranking.com から取得し、`開催日,開催地,定員,受付` の CSV を作る。
取得とパースはサイトの大会スケジュールと同じコード（`src/schedule/parse.ts`）を使うので、自分で HTML を解析しないこと。サイトと結果が食い違わないようにするため。

## 手順

1. **月を決める。** ユーザーの言葉から対象の年月を読み取る。
   - 「来月」「今月」のような相対表現は、日本時間の今日を基準に具体的な年月にする
   - 年が省略されていたら、今日から見て一番近い将来のその月とみなす（例: 今が2026年9月で「1月」なら2027年1月）
   - どの月か判断できないときだけ聞き返す
2. **出力先を決める。** 指定がなければ、ユーザーのダウンロードフォルダに `鬼火CS_YYYY年M月.csv` という名前で保存する（例: `C:/Users/<ユーザー名>/Downloads/鬼火CS_2026年10月.csv`）。リポジトリの中には置かない。ルート直下にファイルを増やさない規約があり、git の差分にも混ざるため。
3. **スクリプトを実行する。** リポジトリのルートで次を実行する。
   ```bash
   npm run -s export-csv -- 2026-10 "C:/Users/<ユーザー名>/Downloads/鬼火CS_2026年10月.csv"
   ```
   月は `2026-10` / `2026/10` / `2026年10月` のどれでもよい。成功すると件数と出力先が表示される。
4. **結果を伝える。** 件数、出力先、CSV の中身（表の形にするか、先頭の数行）をユーザーに見せる。ファイルを渡す手段があれば、それでも送る。

## CSV の中身

```
開催日,開催地,定員,受付
2026/10/04(日),竜星の嵐新宿店,80,10:10〜10:30
2026/10/04(日),晴れる屋3,108,16:50〜17:10
```

- 開催日は曜日付き、日付順（同じ日は開始時刻順）に並ぶ
- 開催地は大会名「鬼火CS in ○○」の ○○
- 受付は開始の20分前〜開始
- 承認が「◎」の大会だけを載せる（「未」はまだ確定していないため、サイトと同じく除外）
- Excel でダブルクリックしても文字化けしないよう、BOM 付き UTF-8・CRLF 改行で書き出す

## うまくいかないとき

- **0件だった**: その月にまだ大会が登録されていない可能性が高い。エラーではないので、0件だったこと（見出し行だけの CSV になったこと）をそのまま伝える
- **「検索結果の表（table#main）が見つかりません」**: dmp-ranking.com の画面構成が変わった可能性がある。`src/schedule/parse.ts` の修正が必要で、サイトの毎日の自動更新も同じ理由で失敗しているはず。ユーザーに伝えて、直すかどうか確認する
- **HTTP エラー**: dmp-ranking.com が一時的に落ちている可能性がある。少し待って1回だけ再実行し、それでも失敗したら伝える
- **列を増やしたい・形式を変えたい**と頼まれたら、`src/schedule/csv.ts` の `eventsCsv` とそのテスト（`csv.test.ts`）を直す。スキルの中で一時的に加工するより、次回以降も同じ結果になる
